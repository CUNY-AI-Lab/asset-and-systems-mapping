# Systems Mapping source and deployment authority

Read `docs/cloudflare-deployment.md`, `docs/REQUIREMENTS.md`,
`docs/MEMO_WORKSPACE_2026-11-04.md`, and `docs/TWO_MEMO_WORKFLOW_2026-11-04.md`
before changing this application. The user's latest November 4 requests govern
the account workspace. Earlier five-stage and two-sphere designs are historical
or belong to the separate Node interface. Preserve compatible stored stage IDs,
map identities, geometry, evidence, annotations, import/export and project links.

The Cloudflare entrypoint is a separate version with independent SQLite-backed
Durable Object storage. The original Node/Railway target and its existing data
are not migrated or retired by this work. Only the Cloudflare frontend build
sets `VITE_ACCOUNT_WORKSPACE=true`. Do not copy test entrypoints or fixture
identity keys into the production configuration.

Consult current remote `CUNY-AI-Lab/cail-knowledge-base` and owning service source
for institutional contracts. Forward only the separately verified, matching
Gateway identity. Gateway changes require PRs; do not merge or deploy Gateway
as part of a product release. Do not introduce provider keys, hidden retries,
local model-spend admission, or payload/identity logging.

Preserve recovery copies and optimistic revisions. An account change must not
make an old browser tab write into the new account. A code rollback never
authorizes a database rollback. Report source tests, hosted CI, deployed source,
and real signed-in model acceptance as separate evidence.

The account workspace opens the canvas first and keeps Memo, Notebook and Tools in one resizable sidebar. Two independent memos feed four direct analytical steps and three nested spheres. Continue is gated only by a successful memo-to-nodes submission for the current part, including an empty result; notes and relationships are optional. A memo update uses that part's last-successful baseline and stable original identities, preserves student edits and removals, and applies graph plus baseline in one undoable transaction. No unchanged memo paid regeneration or automatic relationship generation. Classification is relative to focal participation and pathways, not proper names or organizational size.

Projects uses a two-field Project title / Creator name form, keeps those values separate, and preserves existing names. Saved rows show title and creator; Project details edits both. Memo/Notebook/Tools use an active underline, not filled tabs. The generic private-information checkbox is removed while stored declarations and required legacy consent remain intact. Dev and production report configuration sends new bug reports and feature requests directly to Redmine with no email fallback; retain earlier receipt recovery.

Keep progression and item actions at the top, stateful Add to map/Remove, optional Field Notes, distinct view Back and saved content Undo/Redo. Node colors are presentation only: Automatic or the shared six-color palette; preserve them in history and exports. Double-click starts a student connection to an existing node or a new node at empty canvas; require relationship wording before atomically saving, and leave no partial records on cancel. The information flag uses the exact approved copy, a pausable 12-second timeout and no focus steal. Preserve `reflection` storage keys, numeric stage IDs, earlier prose and recovery journals. Do not revive suggestion queues, mandatory notes, the Map button or a visible Edit caption. The separate Node application retains its legacy review workflow. `wrangler.dev.jsonc` deploys the separate Dev Worker; production stays manual after Dev verification.

Instructor prompt editing follows `docs/instructor-settings.md`: one scale selector and prompt field, optional student preview, and Publish changes that saves pending edits first. Routine editing generates draft metadata; preserve optimistic revision checks, failed-publication drafts, and the advanced version/history controls.
Course rosters stay in a collapsed disclosure under Submissions and load on demand; they must not displace the console navigation or course-settings editor.
