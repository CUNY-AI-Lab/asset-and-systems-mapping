# Student pedagogy copy before and after

Updated: 2026-08-28

## Scope

This ledger records student-facing literal copy changed in the current working comparison for `src/App.jsx`, `src/MapListView.jsx`, and the import message in `src/domain.js`. It includes visible labels, help text, status messages, validation and recovery messages, accessible names, and student exports. Internal identifiers, code comments, test fixtures, server prompts, and Teacher Console copy are outside this ledger.

`Before` reproduces the earlier literal. `After` reproduces the current literal. `Not present` marks newly added copy; `Not present` in the After column marks removed copy. Dynamic values appear in braces. Git commit history is the durable direct diff; this ledger remains a readable copy inventory.
