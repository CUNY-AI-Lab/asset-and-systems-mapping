Built through the Critical AI Literacy Institute. A continuing project with the CUNY AI Lab.

Systems mapping helps students visualize memos as network graphs scaffolded across local and global scales, using asset and systems mapping theory to connect nodes across people and places, laws and policies, along with broader historical and sociological influences.

Upload your first memo to place people, places, and resources on the map, then use Notebook to create and label their relationships. Add your second memo to extend the map to institutions and broader conditions; edit either memo in Memo and choose Update map to incorporate your changes.

Design behavior: Canvas remains visible. Memo, Notebook, and Tools share the same resizable right panel. A brief highlight points to Memo only when a memo is needed. The info flag closes automatically, pauses while being read, and can always be reopened. Continue is available after the current memo has generated its nodes; connections and notes never block progression. Updates use changed passages plus existing map context; untouched work stays intact. Node colors are optional. Double-click a node to start a connection to another node or empty canvas. This prototype makes no model calls and saves no project data.
