Later direct user decisions supersede earlier specifications. The current progression is Micro, Meso, Exosphere, and Macrosphere. Micro generates nodes only. Meso carries those same node IDs forward and first introduces connections. Exosphere replaces Macro; Macrosphere replaces Integration. Instructor review stays advisory, and no review result or outstanding evaluation may block another level, stage, or cycle.
