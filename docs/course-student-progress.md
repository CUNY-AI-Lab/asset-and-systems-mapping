# Course sign-in and saved progress

General account access discovers currently allowed courses through fresh Admission receipts. Each enrolled participant's first successful discovery or course account load records the first visit in that course's existing Durable Object. Repeat visits update the latest visit without replacing the first. Course discovery runs independently of ordinary map opening and has an eight-second deadline.

The course owner can view Students and saved progress in Instructor Console. Each page rechecks ownership and obtains up to 40 current roster members from Admission; only members with a recorded application visit appear. Names come from verified Admission profiles. Students with no saved course maps have a first-map-pending status. Each student's latest 20 saved maps show revision, save time, and per-level stage. General maps remain private to the general workspace.

The roster join uses application-specific member IDs within the selected course. Course ownership governs reads even for Lab administrators. Failed refreshes clear previously displayed roster content. The additive visit table preserves existing maps, identities, enrollments, prompt versions and application bindings.

Local checks cover first visit, repeated access, saved inactive Meso progress, current owner authorization, revocation, cross-course denial, strict Admission receipt parsing, and clearing UI content on authorization failure. Live Maria and Cen sessions require each person to sign in themselves; synthetic test identities establish code behavior only.

The account student interface now presents four direct analytical steps within Memo · Notebook · Tools. Existing per-level numeric stage fields and aggregate IDs remain compatible; they do not imply that a student must visit five review screens. Field Notes are optional and Continue requires only the current part's successful memo submission. Memo baselines, node colors and saved edit history remain private project data; this UI change adds no roster fields or instructor access. See [Memo workspace](MEMO_WORKSPACE_2026-11-04.md).
